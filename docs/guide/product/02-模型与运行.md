# 产品篇 02：准备模型，完成第一次运行

> 主题：从源代码和模型文件到一次终端运行。
> 读者：第一次使用 mini-llama 的使用者。
> 依据：README.md、src/main.cpp、本次会话历史运行记录。
> 规范：tech-doc v1.1；命令均从项目根目录执行。

## 1. 需要准备什么

需要 C++17 编译器、CMake、ccache，以及支持 POSIX mmap 的系统。本机环境为 Linux。程序只依赖标准库和系统内存映射接口，模型文件需要另行准备。

模型是训练的结果，内部主要包含网络各层的数字参数，以及把文本映射到数字的词表。GGUF 是承载这些信息的一种文件格式，类似“装模型的容器”，不是网络架构名称。

| 文件名的一部分 | 表示什么 |
|---|---|
| TinyLlama | 模型系列 |
| 1.1B | 约 11 亿参数的规模标识 |
| Chat | 面向对话使用的模型版本标识 |
| Q8_0 | 权重采用的量化格式标识，不代表所有张量类型都相同 |
| .gguf | 文件格式 |

本仓库 models/ 下已有 TinyLlama-1.1B-Chat-v1.0.Q8_0.gguf。本次历史运行可以装载它，但输出出现了特殊占位文本；这说明“能够装载”和“生成质量正常”需要分别验证。

## 2. 构建程序

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER_LAUNCHER=ccache \
  -DCMAKE_C_COMPILER_LAUNCHER=ccache
cmake --build build -j6
```

得到的主要程序有：

| 程序 | 用途 |
|---|---|
| build/mini-llama | 加载模型并生成文字 |
| build/mini-llama-lines | 选择一条教学业务线运行 |
| build/line_prefill 等 | 单独运行某条业务线 |
| build/test_* | 测试入口 |

## 3. 实例：生成一段续写

输入是模型路径、起始文字和参数：

```bash
./build/mini-llama \
  --model models/TinyLlama-1.1B-Chat-v1.0.Q8_0.gguf \
  --prompt "The capital of France is" --n 16 --temp 0
```

下列为本次会话此前执行该命令的历史输出，耗时仅代表当时机器状态：

```text
模型: models/TinyLlama-1.1B-Chat-v1.0.Q8_0.gguf  层数=22  维度=2048  头=32/4  词表=32000
prefill 完成: 12 tokens
<s> The capital of France is 1000 francs. [control_11][control_11]2.[control_448] ca[control_681]
生成 16 tokens，耗时 36.4462s（0.439003 tok/s）
```

如何读这段输出：

- 第一行是模型配置摘要，不是回答内容。
- 第二行说明输入被编码成 12 个 token，并已处理完毕。
- 正文先回显编码后再解码的输入，然后接上生成内容。
- 最后一行统计生成循环，不包含模型加载和输入预填充的全部耗时。

这里的续写没有正确回答“法国首都”问题，并带有 `[control_N]`。不能把它当作成功问答范例，也不能仅凭该输出确定根因。此前检查发现这些占位文本确实存在于当前文件的词表中；模型来源、词表与权重的匹配、提示格式和计算兼容性需要分别核对。

## 4. 成功、停止和失败

| 情况 | 程序行为 | 使用者怎么办 |
|---|---|---|
| 达到 --n 上限 | 输出统计并正常退出 | 要更长续写可调大上限，注意计算时间与上下文容量 |
| 生成结束 token | 提前停止，不打印该结束 token | 属于正常结束，不承诺一定生成满 --n |
| 缺少模型路径或输入文字 | 显示用法，退出码 2 | 补全参数后重试 |
| 文件路径错误、文件不可读 | 显示错误，退出码 1 | 修正路径或权限后重试 |
| 文件、张量类型或形状不受支持 | 加载或计算阶段报错 | 核对支持范围；原样重试不会解决兼容问题 |
| 输出不符合事实 | 仍可能正常退出 | 正常退出只表示执行结束，不证明回答正确 |

例如不传任何参数：

```bash
./build/mini-llama
```

按当前 main 的分支会显示用法并返回 2。其输出形状如下，属于代码推导示例：

```text
./build/mini-llama --model X.gguf --prompt "文本" [--temp 0.8] [--top-k 40] [--top-p 0.95] [--n 128] [--seed 1234]
```

## 5. 使用边界

运行只读取模型，不修改原始权重；生成历史存在进程内，CLI 没有保存和恢复聊天会话的功能。不要把一次执行结束理解为模型已经“记住”了这次对话。
