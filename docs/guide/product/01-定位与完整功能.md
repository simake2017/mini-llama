# 产品篇 01：mini-llama 是什么，能做什么

> 读者：没有使用过模型推理程序的新手。
> 主题：软件定位、完整能力、输入输出和使用边界。
> 依据：项目 README、PROJECT.md 与 src/main.cpp。
> 规范：tech-doc v1.1，面向使用者表达。

## 1. 先用一句话认识它

**mini-llama 是一个在自己电脑上运行语言模型、根据输入文字生成后续文字的命令行程序，也是学习这种程序如何工作的教学项目。**

它的基本使用方式是：准备一个已经训练好的模型文件，给程序一段文字，程序读取模型并计算，随后逐段输出续写。

比如输入“法国的首都是”，模型可能继续生成“巴黎”。这句话只是用途示意，不是本项目已验证的运行结果。程序不会查询事实数据库，生成内容也不保证正确。

## 2. 程序、模型和输入文字分别是什么

| 名词 | 新手可以怎样理解 | 本项目中的例子 |
|---|---|---|
| 推理程序 | 负责运行模型的软件 | build/mini-llama |
| 模型文件 | 训练完成的数字参数和配套词表 | models/ 下的 .gguf 文件 |
| 提示词（prompt） | 交给模型的起始文字 | The capital of France is |
| 推理 | 使用已有参数计算后续文字 | 每次计算下一个 token 的分数 |
| token | 模型处理文字的单位，可以是字、词的一部分或字节 | Hello 和 world 不一定各是一个 token |
| 生成结果 | 程序选择并拼接的新 token | 一段续写文本 |

模型文件不是程序源码。换模型，模型的知识、表达能力和词表会变；换推理程序，则改变模型怎样被执行。

### LLaMA、llama.cpp 和 mini-llama 的区别

- **LLaMA**：语言模型家族。模型具有训练好的参数和网络结构。
- **llama.cpp**：运行语言模型的开源推理引擎，具有多种架构、硬件后端和工程功能。
- **mini-llama**：本仓库的教学推理程序，挑选并还原 llama.cpp 中的一条推理主干。

本指南介绍 mini-llama 的全部主要能力。不能把完整 llama.cpp 的功能列表当成本项目的功能列表。

## 3. 它有哪些功能

| 功能 | 你提供什么 | 程序做什么 | 你得到什么 |
|---|---|---|---|
| 模型加载 | 受支持的 GGUF 文件路径 | 读取结构、词表与权重 | 可以进行计算的模型 |
| 文本编码 | 一段文字 | 拆成模型可用的整数编号 | token 编号序列 |
| 模型计算 | token 编号与历史上下文 | 运行神经网络 | 下一个 token 的候选分数 |
| 文本生成 | 模型、提示词、生成参数 | 反复计算和选择下一个 token | 连续输出的续写文字 |
| 生成控制 | 温度、候选范围、长度、种子 | 控制选择方式和停止条件 | 更确定或更随机的生成过程 |
| 历史缓存 | 当前已处理的上下文 | 保存历史计算的 K/V 向量 | 后续步骤复用历史结果 |
| 量化模型读取与计算 | 支持格式的压缩权重 | 反量化并参与计算 | 能使用部分低精度模型权重 |
| 过程观测与验证 | 业务线命令或测试命令 | 打印中间状态、检查约定 | 观察加载、分词、缓存、采样等过程 |

有些能力供最终用户直接调用，如文本生成；另一些是生成背后的内部机制，如缓存和量化。业务线工具把这些内部能力展示出来，便于学习。

## 4. 它能用来完成哪些任务

语言模型通常可以通过输入文字表达续写、问答、改写、摘要或代码补全等意图。本程序提供的是生成通道；这些任务是否完成得好，取决于模型、提示格式及本实现的兼容程度。

| 任务意图 | 输入示意 | 希望得到的结果 | 本项目的承诺边界 |
|---|---|---|---|
| 续写 | 从前有一座山 | 后续故事 | 能执行生成循环，不保证故事质量 |
| 问答 | 法国的首都是哪里？ | 一个回答 | 没有事实核查，不保证正确 |
| 改写 | 请把下面的话改得简短：…… | 改写后的文字 | 依赖模型的指令理解能力 |
| 学习推理机制 | 运行 prefill 业务线 | 缓存和打分观测 | 有专门的教学入口与校验 |

这些任务没有各自独立的“摘要接口”或“问答接口”，最终都是把文字送入同一个生成过程。本项目没有网页聊天界面、HTTP 服务或自动对话模板处理。

## 5. 一次使用从头到尾是什么样

1. 准备模型文件。
2. 指定文件路径和起始文字。
3. 程序读取模型，并处理输入文字。
4. 程序逐 token 输出续写。
5. 遇到结束 token 或生成长度上限时停止；发生错误则退出并显示错误信息。

实际命令、历史输出与失败处理见 [02 模型与运行](02-模型与运行.md)。

## 6. 明确不做什么

- 不训练、微调或下载模型；模型需要事先准备。
- 不提供数据库式事实检索、联网搜索或知识库问答系统。
- 不提供生产服务所需的多用户并发、HTTP API 和会话管理。
- 不实现 CUDA、Metal 等 GPU 后端；本项目以 CPU 直接计算为主。
- 不支持所有 GGUF 模型。文件格式、分词器和网络架构是不同的兼容层次。
- 不复制完整 llama.cpp 的全部模型架构、采样方式和性能优化。

## 7. 新手应当怎样判断它是否适合自己

想学习“文件里的模型怎样把文字变成续写”，适合从这里入门。想直接获得高速、稳定、功能丰富的聊天服务，应选成熟的推理产品；本项目的主要价值是代码和运行过程都可以拆开看。
