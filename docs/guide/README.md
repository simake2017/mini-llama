## 先认识它

mini-llama 是一个 C++17 编写的、运行在 CPU 上的大语言模型推理程序。它加载已经训练好的模型，把输入文本变成 token，计算下一个 token 的分数，选出一个结果，再不断重复，最终输出续写文本。

它相当于“执行模型的引擎”。训练好的模型文件提供参数和词表；程序负责读取、计算、采样和输出。它本身没有固定的知识库，也不负责训练模型。

本项目是 llama.cpp 推理主干的教学还原，覆盖单模型、单序列、LLaMA 风格网络。支持某种分词器或 GGUF 文件格式，不等于支持使用该格式的所有模型架构。

## 项目分成什么

按实现能力分为五个单元：GGUF 加载、分词、前向计算、KV Cache 与采样生成、量化。量化是加载和前向计算使用的数值能力，不能理解为文本生成结束后的第五道工序。

按执行过程可分为六步：加载模型 → 编码输入 → 处理整段输入 → 选出新 token → 增量计算并循环 → 解码输出。实际 CLI 在循环中边解码边输出。

按教学观测划分为四族八条线：load、text、infer、numeric。它们调用核心 API，提供逐跳观测，不是另一套推理实现。

## 实例口径

- **历史实测**：来自本次会话此前运行的输出，注明命令、截取范围；模型或程序变化后数值可能改变。
- **原理示例**：用小数组解释数学或内存形状，明确标注，不冒充真实模型结果。
- **可运行命令**：可在项目根执行。未提供实测结果的命令，不承诺具体生成文本。
